# 视频转透明 GIF 应用

一个简单易用的 H5 应用，可以将视频文件转换成透明背景的 GIF 动图。

## 功能特性

✨ **核心功能**
- 📹 支持多种视频格式（MP4, WebM, MOV 等）
- 🎨 自动移除背景生成透明 GIF
- ⚙️ 可调节参数（帧率、质量、缩放、透明度阈值）
- 📱 响应式设计，支持移动端和桌面端
- 💾 一键下载生成的 GIF

🔧 **可调参数**
- **帧率 (FPS)**: 5-30 帧/秒，控制动画流畅度
- **质量**: 1-20，数值越小质量越高（文件越大）
- **缩放比例**: 0.1-1.0，控制输出 GIF 尺寸
- **透明度阈值**: 0-255，控制背景移除的敏感度

## 使用方法

1. **打开应用**
   - 直接在浏览器中打开 `index.html` 文件

2. **上传视频**
   - 点击上传区域选择视频文件
   - 或直接拖拽视频文件到上传区域

3. **调整参数**
   - 根据需要调整帧率、质量、缩放和透明度阈值
   - 透明度阈值较小：只移除非常接近背景色的部分
   - 透明度阈值较大：移除更多相似颜色的部分

4. **开始转换**
   - 点击"开始转换"按钮
   - 等待处理完成（会显示进度）

5. **下载 GIF**
   - 预览生成的透明 GIF
   - 点击"下载 GIF"按钮保存文件

## 技术实现

### 背景移除算法
应用使用色度键控（Chroma Keying）技术实现背景透明化：

1. **采样背景色**: 取视频第一个像素作为背景色参考
2. **颜色差异计算**: 计算每个像素与背景色的欧氏距离
3. **阈值判断**: 差异小于阈值的像素设为透明
4. **边缘柔化**: 对边缘像素进行渐变处理，实现抗锯齿效果

### 使用的技术
- **HTML5 Canvas API**: 视频帧捕获和图像处理
- **gif.js**: GIF 编码和生成
- **Web Workers**: 多线程处理提高性能
- **原生 JavaScript**: 无框架依赖，轻量快速

## 优化建议

### 获得更好的透明效果
1. **选择纯色背景视频**: 单一颜色的背景（如绿幕、蓝幕）效果最佳
2. **调整阈值**: 根据视频背景调整透明度阈值
   - 背景色单一：使用较小阈值（20-30）
   - 背景色复杂：使用较大阈值（40-60）
3. **光照均匀**: 确保视频背景光照均匀，避免阴影

### 控制文件大小
1. **降低帧率**: 减少 FPS 可以显著减小文件大小
2. **降低质量**: 增加质量参数值（10-15）
3. **缩小尺寸**: 降低缩放比例（0.3-0.5）
4. **缩短时长**: 只转换视频的关键片段

## 注意事项

⚠️ **性能提示**
- 视频时长和尺寸越大，处理时间越长
- 建议视频时长不超过 10 秒
- 首次加载需要下载 gif.js 库（约 100KB）

⚠️ **隐私安全**
- 所有处理完全在浏览器本地进行
- 不会上传任何数据到服务器
- 可离线使用（首次需联网加载库）

## 常见问题

**Q: 为什么生成的 GIF 很大？**  
A: 尝试降低帧率、增加质量参数值、减小缩放比例。

**Q: 背景没有完全透明？**  
A: 调整透明度阈值，或确保视频背景是纯色。

**Q: 处理时间太长？**  
A: 缩短视频时长、降低帧率、减小缩放比例。

**Q: 支持哪些视频格式？**  
A: 浏览器支持的所有格式（MP4、WebM、MOV 等）。
